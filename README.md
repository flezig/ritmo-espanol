# Ritmo Español

Интерактивный тренажёр испанского языка для русскоязычных учеников. Проект
объединяет последовательные уроки A1, словарь, адаптивное интервальное
повторение, грамматику, диктанты, упражнения по песням и игровые режимы.

## Возможности

- 1162 слова в 17 русскоязычных темах с естественными примерами и полным переводом;
- 5 подробных уроков по 50 заданий;
- грамматические разделы, построенные по хронологии учебника И. А. Дышлевой;
- адаптивное повторение узнавания, активного воспроизведения, артиклей и аудирования;
- Practice с ручным вводом, аудио, контекстом, исправлением ошибок и вариантами ответа;
- игры «Детектив по тексту» и Spanish Rush;
- музыкальные упражнения с короткими фрагментами YouTube;
- диктант по словам из пройденных уроков и Practice;
- регистрация по email и паролю и синхронизация прогресса между устройствами;
- профиль, XP, серии, прогресс и 68 достижений с локальной офлайн-копией;
- отправка отмеченных примеров и упражнений автору сайта;
- экспорт и импорт резервной копии JSON;
- светлая и тёмная темы, адаптивная навигация для телефонов и планшетов.

## Технологии

- React 19;
- TypeScript;
- Vinext и Vite;
- Tailwind CSS;
- Cloudflare Workers/Wrangler для production-preview;
- Supabase Auth и Postgres с Row Level Security для аккаунтов и прогресса;
- Node.js `node:test` для автоматических тестов.

## Требования

- Node.js 22.13 или новее;
- pnpm 11.19 или совместимая более новая версия.

Если pnpm ещё не установлен:

```bash
corepack enable
corepack prepare pnpm@11.19.0 --activate
```

## Локальный запуск

```bash
git clone <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
cd ritmo-espanol
pnpm install
pnpm dev
```

Откройте адрес из терминала, обычно `http://localhost:3000`.

Без переменных Supabase сайт продолжает работать в гостевом режиме и хранит
прогресс только в браузере.

## Настройка регистрации и облачного прогресса

1. Создайте проект в [Supabase](https://supabase.com/dashboard).
2. Откройте `SQL Editor`, вставьте содержимое
   `supabase/migrations/0001_user_progress.sql` и выполните запрос. Он создаст
   таблицы прогресса и жалоб, а также правила, по которым пользователь видит
   только собственные записи.
3. В `Authentication → URL Configuration` укажите публичный адрес сайта как
   `Site URL` и добавьте этот же адрес в `Redirect URLs`. Для локальной проверки
   добавьте `http://localhost:3000`.
4. Скопируйте из `Project Settings → API` значения `Project URL` и публичный
   `anon`/`publishable key`.
5. Для локальной разработки создайте `.env.local` по образцу `.env.example`:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://ВАШ_ПРОЕКТ.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=ВАШ_PUBLIC_ANON_KEY
```

6. В настройках сборки Cloudflare добавьте эти же две переменные окружения и
   запустите новый deploy. Это публичные клиентские параметры; ключ
   `service_role` добавлять на сайт нельзя.

Регистрация переносит текущий гостевой прогресс в новый аккаунт. После входа
синхронизируются профиль, уроки, словарь, интервалы SRS, история слов,
достижения, Practice, диктант, игры, избранное, пользовательские слова и
отметки контента. Локальная аналитика намеренно остаётся только в браузере.

Отмеченные пользователями задания доступны владельцу проекта в Supabase:
`Table Editor → content_reports`. Для очереди на проверку используйте фильтр
`status = pending`; после исправления можно вручную поставить `resolved`.

## Хранение данных и приватность

Без входа учебные данные сохраняются в `localStorage` текущего браузера. После
входа сайт оставляет локальную офлайн-копию и синхронизирует учебные данные с
записью пользователя в Supabase. При выходе локальная копия аккаунта очищается,
чтобы она не оставалась доступной следующему человеку на общем устройстве.

Схема хранения версирована, новые типы контента добавляются под новыми
стабильными идентификаторами. Идентификаторы существующих уроков, тем и слов
нельзя переиспользовать или перенумеровывать: это сохраняет старый прогресс при
обновлениях курса. Перед крупным изменением формата данных добавляйте миграцию в
`app/lib/storage-version.ts` и увеличивайте версию резервной копии.
Встроенные музыкальные задания обращаются к YouTube и зависят от его доступности
в регионе пользователя.
